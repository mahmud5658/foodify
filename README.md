# 🍽️ Foodify

**Foodify** is a modern, scalable food ordering mobile application built using **Flutter** and **GetX**. It connects seamlessly to **Supabase** for backend functionalities like authentication, real-time database, and storage.

This project follows a clean and modular architecture to promote scalability and ease of maintenance.

---

## 📱 Features

- 🔐 Supabase authentication
- 🛒 Shopping cart functionality
- 🧭 Clean navigation using GetX routes
- 🎨 Custom themes and reusable UI components
- 🧩 Modular structure with separation of concerns
- ⚙️ Dependency injection with GetX bindings
